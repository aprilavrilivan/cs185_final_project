# Dataset Availability

The original experiments used a benchmark of **5,000 preference pairs**. Raw prompt,
response, and preference JSONL files are intentionally excluded from this portfolio
snapshot because they contain open-domain third-party text that may include personal
or sensitive information.

`wildchat_min4_judged_5k_v1/manifest.json` retains sanitized split counts and records
that the raw data are not distributed. Reproduction requires separately authorized
access to the original dataset.

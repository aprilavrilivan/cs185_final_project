# Attribution and Portfolio Notice

This repository is a cleaned portfolio snapshot of Yifan Xu's UC Berkeley CS 185/285
LLM reinforcement-learning final project.

## Source Attribution

The project began from course starter code distributed by
`berkeleydeeprlcourse/homework_spring2026`. Portions of that starter code remain in
this repository under the MIT License. Yifan Xu's implementations, experiment
configurations, analysis, and post-course documentation are presented alongside the
starter structure. The retained MIT license identifies both copyright holders; it
does not imply endorsement by UC Berkeley or the course staff.

## Portfolio Report Status

The document in `report/` is explicitly a **Portfolio Technical Report**. It was
prepared after course completion from Yifan Xu's original code, experiments, and
submitted materials. It was not the report submitted for grading, is not an official
course artifact, and must not be represented as either.

Editorial organization and typesetting of the post-course portfolio report were
assisted by OpenAI Codex. The underlying implementation and experiments are Yifan
Xu's, and all numerical statements in the report are restricted to preserved original
experiment records.

## Excluded Material

This snapshot excludes raw open-domain prompts and responses, per-example generations,
detailed judge outputs, model checkpoints, caches, build products, and submission
bundles. Their omission is intentional and does not alter the aggregate experiment
records retained in `experiments/` and summarized in `RESULTS.md`.

The exclusions above describe the current tree. This preparation intentionally does
not rewrite Git history; prior commits may retain files removed from the current tree.
